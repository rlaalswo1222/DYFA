# Did You Finish Your Homework?

> **과제 마감, 이제 까먹지 마세요.**
> 충북대학교 블랙보에 올라온 과제의 마감이 다가오면 Slack 메시지로 알려 주는 프로그램입니다.

---

## 🤔 이게 뭔가요?

대학생이라면 이런 경험 한 번쯤 있죠.

- "어? 이 과제 마감이 오늘까지였어?"
- 이캠퍼스에 들어가 봐야 과제가 있는지 알 수 있다.
- 과목이 많아서 공지, 과제, 성적이 뒤죽박죽 섞여 있다.

**DYFA**는 이런 문제를 덜어 주려고 만든 프로그램입니다.
사람 대신 이캠퍼스(충북대학교 Blackboard)에 들어가서 새 소식을 확인하고,
**과제 마감이 가까워지면 Slack(메신저)으로 알림을 보내 줍니다.**

쉽게 말해, **"과제 마감 알려 주는 비서"** 입니다. 📬

---

## ✨ 무엇을 해 주나요?

| 기능 | 설명 |
|---|---|
| 🔐 **자동 로그인** | 아이디와 비밀번호를 입력하면 프로그램이 대신 이캠퍼스에 로그인합니다. |
| 📋 **새 소식 모아 보기** | 이캠퍼스 '활동 스트림'에 올라온 소식을 **제공 예정 / 오늘 / 최근 항목**으로 나눠 가져옵니다. |
| 🗂️ **종류별 정리** | 가져온 소식을 **공지사항, 과제, 성적, 강의자료**로 분류합니다. |
| 💯 **성적 확인** | 내 점수를 `내 점수 / 만점` 형태로 정리합니다. |
| ⏰ **마감 알림** | 과제 마감이 **하루(24시간) 전, 5시간 전, 1시간 전**이 되면 Slack으로 메시지를 보냅니다. |

### 이런 메시지가 와요

```
자료구조의 [3주차 과제] 과제가 1일(24시간) 남았습니다.
자료구조의 [3주차 과제] 과제가 5시간 남았습니다.
자료구조의 [3주차 과제] 과제가 1시간 남았습니다.
```

---

## ⚙️ 어떻게 동작하나요?

사람이 하던 일을 그대로 프로그램이 따라 합니다.

```
 1. 크롬 브라우저를 엽니다
        ↓
 2. 이캠퍼스에 로그인합니다
        ↓
 3. '활동 스트림' 페이지를 읽습니다
        ↓
 4. 공지 / 과제 / 성적 / 강의자료로 나눕니다
        ↓
 5. 과제마다 마감까지 남은 시간을 계산합니다
        ↓
 6. 마감이 가까우면 Slack으로 알림을 보냅니다
        ↓
 7. 잠시 뒤 처음부터 다시 확인합니다 (반복)
```

- **크롬을 대신 조작하는 부분**은 `Selenium`이라는 도구가 맡습니다. (사람이 클릭하고 타자 치는 걸 프로그램이 대신 해 줍니다.)
- **웹 페이지에서 필요한 글자만 골라내는 부분**은 `BeautifulSoup`이라는 도구가 맡습니다.
- **Slack으로 메시지를 보내는 부분**은 Slack이 제공하는 메시지 전송 기능(API)을 사용합니다.

---

## 🛠️ 실행하려면 무엇이 필요한가요?

1. **Python** (파이썬) 3
2. **Google Chrome** 브라우저와, 버전이 맞는 **ChromeDriver**
   - 코드에서는 `C:\Chrome_Driver\chromedriver.exe` 위치에 있다고 가정합니다.
3. 아래 파이썬 라이브러리
   ```bash
   pip install selenium==3.14.1 beautifulsoup4 requests
   ```
   > ⚠️ 최신 Selenium(4.x)에서는 일부 코드가 동작하지 않으니 **3.14.1 버전**을 설치하세요.
4. **Slack 봇 토큰**과 알림 받을 **채널**
   - `main.py` 안의 `token = "[사용자토큰]"` 부분에 내 Slack 봇 토큰을 넣습니다.
   - 기본 채널은 `#chatbot`입니다. 바꾸려면 `channel` 값을 수정하세요.

## ▶️ 실행 방법

```bash
python main.py
```

1. 크롬 창이 열립니다.
2. 터미널(검은 창)에 `user_id :`가 나오면 **학번**을 입력합니다.
3. `user_pw :`가 나오면 **비밀번호**를 입력합니다.
4. 이후 프로그램이 알아서 과제를 확인하고, 마감이 가까우면 Slack으로 알려 줍니다.

> 🔒 아이디와 비밀번호는 어디에도 저장되지 않고, 로그인할 때만 사용됩니다.

## 📁 파일 구성

| 파일 | 하는 일 |
|---|---|
| `main.py` | **실제로 실행하는 파일**입니다. 아래 기능을 모두 합쳐 놓았습니다. |
| `login_BB.py` | 이캠퍼스 로그인 기능 (개발용 조각) |
| `stream_BB.py` | 활동 스트림 페이지를 불러오는 기능 (개발용 조각) |
| `Stream_Crawling.py` | 과목 이름과 게시물 제목을 가져오는 기능 (개발용 조각) |
| `Category.py` | 공지/과제/성적/자료 종류를 알아내는 기능 (개발용 조각) |
| `GUI_category.py` | 종류별로 목록을 나누는 기능 (개발용 조각) |
| `Score.py` | 성적을 가져오는 기능 (개발용 조각) |
| `Deadline.py` | 과제 마감 시간을 가져오는 기능 (개발용 조각) |

> '개발용 조각' 파일들은 기능을 하나씩 만들고 시험해 본 파일입니다. 혼자서는 실행되지 않고, 완성된 내용은 모두 `main.py`에 들어 있습니다.
